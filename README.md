# 🌐 Malvin's Personal Portfolio

Hi! This is my personal portfolio website built with [Next.js](https://nextjs.org/) and [Tailwind CSS](https://tailwindcss.com/).  
It showcases my projects, skills, and a bit of my personality — all in one responsive, fast, and clean design.

## ✨ Features

- ⚡️ Built with Next.js App Router
- 🎨 Styled with Tailwind CSS & shadcn/ui
- 🌓 Dark mode support
- 🧩 Fully responsive across devices
- 🔗 Project links, GitHub integration
